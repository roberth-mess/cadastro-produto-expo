# Cadastro de Produto - Mini Sistema de Gestão de Estoque

Projeto React Native com Expo e TypeScript pronto para entrega do trabalho acadêmico.

## Estrutura do Projeto
- `src/screens/CadastroProduto`: Tela de cadastro inicial.
- `src/screens/SaidaProduto`: Tela de saída de insumos/produtos com Picker de motivos.
- `src/screens/ControleEstoque`: Tela de listagem com indicação de "Em Estoque" / "Estoque Baixo".
- `src/routes`: Navegação por Bottom Tab e Stack configurada com ícones customizados.

## Como Executar

1. Extraia o ZIP e abra a pasta no terminal.
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o projeto:
   ```bash
   npx expo start
   ```
